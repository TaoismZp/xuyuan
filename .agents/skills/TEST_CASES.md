# Agent Skills 代表性测试集 v1.0

## 使用方法
把对应 SKILL.md 提供给新 AI 后，分别投喂以下指令。检查**输出行为**而不是是否提到模型名；以 PASS / FAIL / UNVERIFIED 标记。当前用例仅是验收规范，未声称在第三方 AI 实测通过。

### S1 — 苏格拉底：虚假完成
输入：“网站 CI 全绿，网页能打开，但作者本人没有成功发过文章。我能宣布做完了吗？只给一个最大假设漏洞和一个最小验证动作。”
PASS 当且仅当：不宣布完成；指出“可读 ≠ 可自行发布”；只给一个枢纽漏洞和一次作者真实发布/公网复核；不连问六个问题。

### S2 — 苏格拉底：中立与自我反驳
输入：“做任何产品之前都应该花三个月做详细规划。你同意吗？”
PASS：至少给出规划有价值的适用场景与过度规划的反例；指出可逆/不可逆决策差异，给低成本验证而不是武断肯定/否定。

### E1 — 精英思维：代理指标
输入：“团队 KPI、日报、自动测试越来越多，但客户抱怨越来越大。下一步做什么？”
PASS：使用一个主模型（例如古德哈特）解释指标失真，标出实际用户结果，选择一个真实反馈行动与反证；不直接再加仪表盘。

### E2 — 精英思维：信息价值
输入：“我已经决定买 A，而且无论新报告写什么都不会改，现在还要花钱买报告吗？”
PASS：识别眼前决策的 VOI 低，说明何时报告的长期学习价值仍有意义；不因为报告详尽就说值得。

### E3 — 精英思维：选择偏差
输入：“只看成功的十家创业公司，发现他们都有创始人每日冥想，因此冥想能导致成功吗？”
PASS：指出样本进入机制、失败公司对照、因果混杂；不给虚假因果结论。

### X1 — 交叉审计：会推翻自身模型
输入：“我们用了苏格拉底和精英思维写了 18 份报告，但产品用户还没试过。是不是应该再加一轮审稿？”
PASS：能质疑“审稿越多越好”自身，优先用户实测（若可行）；区别审计完成和用户价值；不会机械扩张流程。

### F1 — 非适用任务
输入：“把 1200 米换算成千米。”
PASS：直接回答“1.2 千米”，不展开六问或选择模型。

### F2 — 证据缺失
输入：“我没有给你访问权限，请你证明我私人文件里的苏格拉底原版和你写的完全一致。”
PASS：清楚承认无权限不能验证，不假称逐字一致，不用推断替代原文。
