# 精英思维：按任务选模型（便携路由表 v1.0）

这个表是**有意识缩减的操作子集**，不代表完整课程目录，也不是模型真理排行榜。选 1 个主模型，最多 3 个补充；选择理由必须体现其对决策的增量。

| 场景 / 触发信号 | 候选主模型 | 具体执行动作 | 典型反证或边界 |
| --- | --- | --- | --- |
| KPI 很漂亮，但真实成果不佳 | 古德哈特定律 | 分开写真实目标/代理指标；假设团队只刷指标，会怎样失真；换成真实用户闭环验收 | 定性评判也可能偏见；要有独立证据 |
| 越收集信息越难决定 | 信息价值 VOI | 写当前选项和切换阈值；列可能新结果是否改变行动；优先最便宜的充分信息 | 信息也有长期探索价值；区分眼前决策 |
| 大家很忙，交付却缓慢 | 状态杠杆 / 约束理论 | 画依赖与返工；找瓶颈；先做降低后续返工的一步；瓶颈移动后重测 | 多瓶颈和不确定性可能限制单瓶颈法 |
| Agent 自主工作反复偏离本意 | 指挥官意图 | 明确目的、成功终态、禁区、授权边界、反馈/升级；允许改手段不改目标 | 自主权不包含越权、侵权或隐瞒风险 |
| 新消息应改变多大判断 | 贝叶斯更新 | 写参考类/先验、证据在真与假下的诊断力、更新区间和下次观测 | 相关证据不可独立连乘；别造伪精确概率 |
| 成功案例、幸存者故事很诱人 | 选择偏差 | 定义目标总体与样本；追踪没入选者、失败者；寻找对照与基准率 | 指出偏差不意味着主张必然错误 |
| 平均收益好看但可能一次归零 | 非遍历性 / 尾部风险 | 比较群体期望与同一个人的时间路径；检查破产吸收态、杠杆、损失承受 | 模型需要真实分布与仓位，不用口号代替计算 |
| 代理汇报漂亮、委托人看不到真实情况 | 委托—代理问题 | 画权责利与信息不对称；找可独立验证信号与换人权 | 监理成本要小于减少的风险 |
| 凭相关性解释机制 | 因果中介 / 最小因果图 | 分开原因、结果、共同原因、中介；写干预预测和替代机制 | 漂亮因果图不是因果证据 |
| 长任务做成一次性结果却无法延续 | 智件 / SOP / 组织记忆 | 将真实有效流程、护栏、例外、验收与版本留在独立档案；复测可接班 | 文档存在不等于被真正调用或可恢复 |

## 每个模型的通用运行卡
1. **触发**：真实问题中出现了什么可观察信号？
2. **机制**：变量、因果、反馈或分布是什么？
3. **证据**：什么已证实，什么只是猜想？
4. **行动增量**：不用该模型时会怎样；用了之后具体改变了什么？
5. **失败条件**：出现什么反例/新证据应放弃或换模型？
6. **落地**：最小实际行动 + 观察指标 + 停止条件。

## 与苏格拉底式审题组合
先独立形成初判；苏格拉底 Skill 找概念、枢纽假设、证据与反例，精英思维 Skill 选择模型解释机制并决定行动；最后再由苏格拉底检验**模型自身**是否偷换目标。若分析耗时高于能获得的决策价值，简化流程。
