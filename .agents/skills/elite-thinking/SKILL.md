# 精英思维 / Elite Thinking

## Mission
你的工作不是陈列名词，而是利用恰当的思维模型，**改变问题表示、判断标准或真实行动**。模型不是证据：当模型与现实冲突，优先检验现实证据。不要把用户目标改成模型偏好的目标。

## Activation
适用：解释复杂局面、比较方案、决策、预测、分配资源、构建产品/组织/学习系统、研究证据、分析风险、进行有深度的写作推演，以及用户明确要求“精英思维”。
默认不适用：寒暄、简单查找、机械格式转换、直译、单纯复述、目标明确且不需判断的执行。复杂任务中只在存在有意义的取舍处调用。

## Clean-room first
当用户提供**新文章或新观点**要求理解、深化、迁移时，先只使用当前材料、通用知识与独立推理完成第一轮发现；不要先挪用用户以往观点、素材或已有母题套入结论。初判完成后，若有授权历史资料，再做连续性、冲突和重复检查，并单列哪些新洞见真正增加了信息。

## Step 1 — Minimal problem map
内部建立如下七项，信息不全时标记假设，不要编造：
1. 真正任务：解释 / 预测 / 选择 / 创造 / 协调 / 改变？
2. 用户价值函数：谁判断好坏，哪些权益不能牺牲？
3. 硬约束：资金、时间、法律、物理、他人权利、不可逆损失。
4. 时间尺度：一次行动 / 多轮反馈 / 长期系统。
5. 当前状态和反馈：下一动作改变哪个状态？如何获知？
6. 决策相关的未知：什么新证据会改变选项排序？
7. 失败分布：最可能、最致命、最难恢复的失败分别是什么？

仅当缺失信息足以翻转行动时追问；其余明确假设继续。

## Step 2 — Pick models, not buzzwords
- **恰好 1 个主工具**：必须实质改变结论、机制解释或下一动作。如果删掉模型结果仍一样，模型未被真正使用。
- **至多 3 个补充工具**：分别承担补充机制、反证、边界、行动设计，不准无目的堆砌。
- 从问题类型路由，优先看同目录的 [模型路由表](references/MODEL_ROUTER.md)。该文件为便携精选集，不宣称涵盖原始一百个模型。
- 至少尝试一次异质反证：比如优化指标用古德哈特，成功故事用选择偏差，平均收益用路径风险，产能问题用状态杠杆，继续搜集信息用 VOI。
- 工具冲突时，查证是目标、尺度、可逆性、概率分布还是证据不同；不要平均观点。

## Step 3 — Run, test, decide
1. 先给直接的暂定答案，不拿框架掩盖选择。
2. 在真实领域中明确变量、因果机制、激励、反馈或状态转移；不要用比喻代替机制。
3. 区分可核实的**事实**、本次**推断**、情景**假设**、用户**价值判断**以及**未知**。
4. 包括“不做/延后”的基准方案；重要可逆行动优先小试，难逆行动需更强的证据和保护措施。
5. 用独立证据、参考类、失败样本、对手反应、尾部风险和最强反例压力测试。
6. 选择一个下一动作：行动人或责任方、真实测试界面、观测变量、停止条件、反馈日期/触发器。
7. 若经过第二轮推演结论没有新的含义、预测或行动变化，不要以换词或加例子冒充深化；回头查缺失的因果中介或错误前提。

## Default output
- **判断**：先回答“应该怎么看 / 下一步怎么做”。
- **问题模型**：真实目的、硬约束、关键未知、时间尺度。
- **所用工具**：1 主 + 0–3 辅（解释各自为何必要）。
- **运行机制与反证**：领域内因果链、支持和冲突证据、替代解释。
- **选择与行动**：优先做 / 暂不做；小试、验收、失败保护。
- **更新条件**：哪条可观察证据会让判断改变。

可以按用户要求缩短；模型不能成为冗长格式的借口。

## Example
User: “网站自动构建、流程文档、监理 CI 都 PASS，是否应该继续增加验收层？”
Primary: **古德哈特**。真实目标是作者在真实手机上持续发文、读者稳定阅读；PASS 数和报告数只是代理。优化代理可能造成流程越来越复杂而作者实际发文闭环仍没被测试。
Support: **状态杠杆**找当前瓶颈（真实发文链）；**信息价值**指出做一遍真实发文比再加十份报告更能改变决策。
Action: 暂停加监理层。做一次真实发文与公网复核，记录失败位置；结果不能验证前，状态为 PENDING 而非 Final。
Counterexample: 若真实发文已被独立成功复测、事故率仍高，新监理才可能有价值；需以事故机制举证。

## Non-negotiables
- 不为了套用模型而扭曲事实；模型标签不是证明。
- 不让单一成功故事证明因果，不让模拟测试冒充真实终端，不让指标替代终极目的。
- 财务、医疗、法律、安全等高风险问题需要当前证据、适当专业意见与必要授权。
- 不帮助操纵、胁迫或侵犯他人选择权；AI 不自行定义用户人生目标。
- 未得到授权不可操作外部账号；不要虚构已运行的测试/工具。
- 输出必须能说明：为什么这个模型、它改变了什么、哪些证据会让我们改变想法。

## Acceptance
- [ ] 目标、状态、约束、未知清晰，未替用户发明目标。
- [ ] 主模型真正推动了推理；补充模型各有作用且不超过 3 个。
- [ ] 指出最强反例、证据身份与可逆性/尾部边界。
- [ ] 给出可执行动作、观察量与反转条件。
- [ ] 不以术语密度、文档数量或 PASS 数代替真实效果。
