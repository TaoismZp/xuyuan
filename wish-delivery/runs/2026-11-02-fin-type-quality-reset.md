# FIN·TYPE Quality Reset｜2026-11-02

执行协议：许愿式交付 v7.2（Compound Quality Reset）。

## 触发
用户整体否定上一版两个一级质量维度：**美工不行、题目不行**。

因此旧版冻结为失败样本，不做局部换皮或润色。

## 本轮重新编译的成品目标
一款移动端优先的金融决策人格产品：
- 题目来自真实金融冲突；
- 每个选项均有合理性与代价；
- 不靠明显正确答案或社会期许完成计分；
- 过程有市场阶段、账户路径和单手结算反馈；
- 结果能说明稳定倾向、反面风险与最暴露用户的一手；
- 视觉脱离上一版暗色终端模板，改为编辑部 / 市场备忘录式产品语言；
- 公开真实入口、移动端闭环、重测都必须自动回归。

## 能力 / 方法采购后的采用原则
- 视觉：采用 subject-specific frontend design、mobile-first、one-question-at-a-time、强层级与少卡片原则；淘汰“暗色=金融感”和通用 SaaS 卡片堆叠。
- 题目：采用 behavior-first situational dilemma + balanced forced-choice 思路；选项尽量在可接受性上接近，减少社会期许。
- 测量边界：保留 FIN·TYPE 为“金融决策人格实验”，不声称经过正式心理测量验证。

## 与失败版的结构差异
- 18 次三选一 → 10 次四选一高张力困境；
- 每题只覆盖两条决策轴，但四个选项覆盖两轴的四种组合；
- 每条轴跨 5 个不同市场情境重复出现，因此总分必为奇数，不需要默认 tie-break；
- 黑绿终端视觉 → 米白纸张 / 深蓝墨色 / 钴蓝交互的编辑部视觉；
- 长表单感 → 五幕市场人生 + 每手结算；
- 结果页加入“最硬的一根轴 / 最摇摆轴 / 最后一手暴露项”。
