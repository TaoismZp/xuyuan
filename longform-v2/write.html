Owner publishing desk

把稿子交给出版系统。

这里不保存任何 GitHub Token。点击发布后会进入你自己的 GitHub 发布表单；提交即触发排版、生成文章页、更新首页与重新部署。

发布一篇新长文

准备好标题、副标题、标签和 Markdown 正文。GitHub 会记录原稿与版本历史，网站只接收通过发布流程生成的成品。

打开安全发布表单 →

支持的正文格式

  • 普通段落与二、三级标题
  • 引用、无序/有序列表
  • 分隔线、行内代码、代码块
  • 标准 Markdown 链接

安全边界：公开网页永远不会要求你粘贴访问令牌。身份验证只发生在 GitHub 自己的页面里；发布动作由仓库 Actions 使用仓库权限完成。
