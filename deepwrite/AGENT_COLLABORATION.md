# DeepWrite｜ChatGPT × Codex 共同迭代入口

**总体目标是改进整个 DeepWrite 研究与写书工作台；不是仅验证 Discovery Gate。**

当前真实生效版本：先实际读取 `deepwrite/CURRENT.json` 和 `wish-delivery/CURRENT.json`，不可把候选规范视为正式版。

## 共同研发的范围

- **思想发现**：问题、反例、竞争解释、第二次发现；`discovery-gate/` 属于此处的候选模块。
- **源材料研究**：从一手事实和作者原始材料构建独立知识地图，区分已知、猜测、反例和证据缺口。
- **书的架构**：读者真正需要学会的独立判断，章节间的必要依赖，禁止先凑目录和字数。
- **全书生产**：多轮推演、重写、编辑、事实及算式校验、章间去重、成品阅读体验。
- **自动执行**：一次指定目标后，在真实能力允许范围内内部多轮研究和写作，失败有停工与恢复，不靠作者逐章回复“继续”；当前E1尚未实现。
- **公正评价**：比较真实完整作品的思想增量、推理、证据、文风和读者收益，独立读者与等预算实验不冒充已完成；当前E2未完成。
- **工程和恢复**：私有项目隔离、事实与版本身份、可回读恢复、交付界面与用户能否真正打开作品。

**研发路径**：真实失败/用户评价 → 跨模块缺陷诊断 → 优先级与可证伪改动 → 局部代表测试 → 整书回归与评价 → 决策是否采纳。禁止“写新skill/新门槛”就自动宣称质量提高。若增加复杂度但未提高输出质量，应考虑删除该机制。
