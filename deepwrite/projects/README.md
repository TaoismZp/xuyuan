# 项目隔离区（公开模板，不存私人书稿）

本目录只允许空项目模板、演示数据、公开安全的测试项目。

**不要在这里直接上传未发表的小说、非虚构正文、私人聊天或作者资料。**

每本实际新书应拥有独立\`PROJECT_ID\`、私有仓库（优先）或经核实的私有隔离目录。当前 GitHub 连接无创建新repo的可用动作时，先在私有文件库建立恢复点，标记 \`GITHUB_PRIVATE_REPO_PENDING\`，待具备权限再迁移。

新对话从 [START_HERE](../START_HERE.md) 发起，并参见 [PROJECT_INIT](../PROJECT_INIT.md)。
