# Rival Probe 1 · v0.1 · experimental, opt-in only

This is one bounded prewriting operation, not an additional Skill, released protocol,
full Discovery Gate implementation, or proven quality improvement.

Before settling an explanatory thesis, choose one genuine uncertainty found in the
common source packet. Within the SAME working-notes allowance as the stable route:

1. State two plausible causally distinct interpretations. Do not invent conflict if
   the sources agree or the proposed alternatives cannot be distinguished.
2. State one observable condition on which their predictions differ, and seek one
   source-based challenge to the initially preferred interpretation.
3. Retain, narrow, or discard the thesis according to the actual evidence. A useful
   new distinction need not reverse the conclusion. If this adds only labels or
   unsupported novelty, abandon this operation and say so in private working notes.

Then execute the same drafting, counterargument, fact-check, editing and final
article workflow. The operation receives no extra research, draft length, or time
allowance. It may consume useful writing time and worsen the article. Existing
DeepWrite already includes counterargument and second discovery: added value over
those operations is an open question, not assumed.

Activate only for an explicitly selected project and exact method commit. To stop,
use the retained stable article/checkpoint; do not overwrite either draft or change
CURRENT. Dependencies tested here: DeepWrite v0.1, parent v7.6, bounded explanatory
article adaptation. Narrative/aesthetic writing and whole books are not tested.
