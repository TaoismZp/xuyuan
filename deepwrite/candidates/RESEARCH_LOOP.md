# v0.2 候选：研究与发现循环

状态：`DRAFT_NOT_ACTIVE`。配合 [v0.2](v0.2.md) 使用；是写作前和跨章时的操作，不是多填一份表。优先复用 CONCEPT_MAP、BOOK_BLUEPRINT、CHAPTER_CONTRACT、AUDIT 和现有检查点。

## 1. 先审研究方向，再审已经写出的论断

从读者问题和源材料出发，建立源领域概念、依赖、重要争论与未知。明确概念图版本、读者合同版本和实际生效的章节计划；它们是三种对象，不能互相冒充。图谱不要求覆盖一门学科的所有知识，但排除哪些重要机制、为什么排除，应能说明。

需要Clean Room重研时，先封存旧稿结论与既有审稿。给原生研究阶段的输入仅含作者问题/价值边界、读者、源领域材料及已知约束；先形成机制与方向候选，再暴露旧稿作比较。可用已有独立上下文，不强制增建Agent系统。若执行者已经看过答案或无法隔离，标明 `UNBLINDED`，不得把“不受影响”的自述叫作清洁室验证。作者身份与问题意识仍保留，隔离的是预设答案。

对核心章节，先提出少量真正不同的研究方向，比较源领域解释力、目标读者价值、证据可得性和与邻章的分工，再决定本轮追哪一条。简单基础解释不强制制造多个方向。保留未选方向及理由，可用几句话写在现有AUDIT里。

问自己：如果不知道上一章的结论，还会选择这个问题吗？当前例子是否只是因为最容易写、最容易类比？哪些源领域机制被这一选择遗漏？若新概念总回到相同母题，或主概念与附属工具混成同级章节，先停扩写，重新核对图和章节计划。

## 2. 推到机制，再在目标域重新建模

先讲清原概念：参与者知道什么、能做什么，规则与约束怎样改变结果；必要时用可复算例子把机制隔离出来，假设与真实数据分开。

跨域时，重新说明目标域的主体、信息、可执行行为、约束与结果。经济题材要进一步核对价格、现金流、权利义务、交易对手及成本；其它题材按其原生变量检查。写出类比失效之处，不能把原域的数字、动作顺序或名称直接搬过去当证明。

作者提供的新材料先问：它改变了什么问题或解释？有什么反证？哪些内容不该进入本章？可以拒绝材料、转交相邻章，或承认它只改善解释而未产生新理论。不编来源来填补研究空缺。

## 3. 让初步答案承受反例，而非安排戏剧反转

挑选最可能推翻当前解释的条件、反例或竞争解释。检查推演后实际改变了什么：新增变量、适用边界、不同情况下的行动或对已知事实的新组织关系。没有改变也可保留，但需说明最强挑战为何未推翻它，不能只增加例子/字数来冒充深化。

核心发现章必须说明：读者比初步答案多获得什么、证据如何支撑、什么仍不能断言。增量也可以是有依据地排除竞争解释、确认初步答案的可靠性及边界；结论未变不等于没有研究贡献。基础章、过渡章按其明确作用验收；不能把失去贡献的核心章临时改称基础章以规避返工。

“第二次发现”保留为继续检验初步答案的压力，不规定发生在正文后半，不要求每章有第二个原理。若无法挣得本章贡献，回研究、缩小范围、合章或放弃，不虚构新奇。

## 4. 同时设置收束点

研究足以成稿的迹象：机制及边界能讲清、关键反例有响应、目标域对应成立（仅跨域项目适用）、本章贡献能与邻章区分，新增材料已不再改变核心理解。此时进入完整正文，而非无限追问“更深”。

反之，局部文章越来越完整但源领域覆盖越来越窄，应退回方向比较，而非继续打磨。连续两轮没有具体改进时先检查瓶颈；必要的精简或KEEP也算有效编辑决策。

## 5. 跨章碰撞要允许改变结构

每3—5章以及发现重大结构问题时，比较章节贡献、源机制覆盖、案例、结论和表达形态，不只做词句查重。逐项裁决：KEEP / MERGE / RESEARCH_MORE / REWRITE / DROP。

两章主旨不同但采用相同案例、同样转折，会削弱全书区分度；可换案例而保留机制。一项机制被人为拆散则合章。概念图和章节计划因研究而变时，记录变更理由及受影响稿件；旧审稿不自动验新正文。

早期与后期使用不同工作流，不等于必须全部重写。按共同质量标准比较正文，保留已经有效的稿件，修真正缺口。统一标准，不统一“场景—数学—案例—升华”的外形。

## 6. 内循环自行推进，作者仍掌握价值选择

完成本章已授权研究、成稿、审查和返工后，在活跃回合内继续已确定的整书范围；不让作者每道门都回复“下一步”。真实阻塞时保存状态、缺件和可执行下一步，不承诺虚假后台。

分别记录作者提供的研究资料、问题/诊断、作品立场/范围选择、实际评价和单纯推进。模型对已授权工作的研究与返工应主动完成；作者的新价值取舍不能由模型自作主张。作者明确接受当前成果并限制重构时，按该边界收尾，后续方向另立候选。

最后执行 EDITORIAL_LOOP 的来源支持、结构、表达、真实读者检查和身份保存。研究记录应解释正文为何改变，不得成为正文的替代品。
