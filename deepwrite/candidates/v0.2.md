# DeepWrite v0.2 候选｜研究、发现与整书重审

状态：`DRAFT_NOT_ACTIVE`。以 v0.1 为比较基线，本页只用于显式选择的开发试验；不改写两份 CURRENT 的生效版本。适用范围仍是长篇非虚构，尚不声称适用于小说、诗歌等全部文体。

## 先判断任务

- **新书**：执行 PROJECT_INIT，核实私有可写持久存储，原稿只读。没有可用私有库工具时不得虚报“已存入私有文件库”；本地临时文件不能等同跨对话存档，记录 `DURABLE_STORAGE_PENDING` 并提供可下载/可复制候选。
- **旧书修订**：先恢复已有项目，保留作者值得留下的段落与版本，不因启动新对话重建项目。
- **工作台本体迭代**：建立独立方法项目与四件套；仅公开方法/合成样例可进入公开库。执行恢复动作前先核任务类型，不能把方法改进请求自动转成“请给一个新书题目”。

## 最小执行路径

读者与声音契约 → 原生概念依赖图（标版本）→ 研究方向比较 → 源领域推演（跨域项目再做目标领域重建）→ 章节贡献与两个不同难点样章 → 章内研究/反证/成稿 → 每3—5章跨章碰撞与方向重审 → 结构和语言编辑 → 整书连读与装订 → 独立验收及作者终审。

先执行 [RESEARCH_LOOP](RESEARCH_LOOP.md)，再执行 [EDITORIAL_LOOP](EDITORIAL_LOOP.md)。主张表检验已经选出的论断，不能代替选题研究和知识地图。不得因稿件事实正确、流畅或局部有新观点，就跳过“研究方向是否值得”这一级审查。

沿用 v0.1 的隐私、版本派生、身份绑定、状态保存和中断恢复要求。新增文件限 [EDITORIAL_BRIEF](../templates/v0.2/EDITORIAL_BRIEF.md)、[CHAPTER_REVIEW](../templates/v0.2/CHAPTER_REVIEW.md)、[CLAIMS](../templates/v0.2/CLAIMS.json)；可合并到既有项目文件中，避免重复填表。正文是 Primary Artifact，表格不能替代正文。

## 八道候选门（不追溯修改 v0.1 的审稿结论）

|Gate|需要证明什么|失败时做什么|
|---|---|---|
|G0 读者与声音|读者先验、阅读目的、结束时的理解/行动变化；作者问题意识、确定性表达与应保留文字；当前有效范围|有合理默认值就注明假设继续；核心价值不明才问作者；新想法先评估影响，不自动重写已认可的作品|
|G1 原生研究与论断|源领域概念、依赖、争论与未知；比较重要研究方向；区分事实/推断/假说/建议/虚构示例|图谱版本/目录混乱、用旧观点反推新概念时停止扩写，先重研；缺证据不制造发现|
|G2 样章校准|两个不同难点（如论证与叙事、基础解释与争议判断）；与正负基线逐段比较|未解决最高风险前不扩大量产；不是为了“风格不同”|
|G3 章节贡献|本章承担解释、论证、叙事、指导或综合中的何种作用；读完具体改变什么|对无贡献内容合并、重研或删除；必要铺垫/检索性复现可保留|
|G4 理解推进|核心论证/发现章须给出受证据约束的新理解，或通过排除竞争解释、确认边界使初步答案更可靠；基础解释章可准确澄清已知，但要服务读者路径|不强制后半反转或改变结论；核心章无研究贡献不能仅以清楚无错过门，应重研/合并/删去，不能制造发现|
|G5 主张支持关系|关键论断的具体来源位置、口径、支持范围、反证；公式复算；审稿绑定当前正文|因果、泛化、跨域迁移越界则重写；只有 URL 或哈希不算事实已证实|
|G6 连读与可读性|检查整书方向与覆盖、跨章分工，再检查前置知识、问题推进、案例和声音；审查母题、案例与形式是否一起固化|先处理选题/结构错误，再改句子；可以合章、更换案例或有依据地KEEP；不把统一工作流等同于统一文章模板|
|G7 真实成品|全书、序尾、必要附录与来源、实际阅读载体、候选/审稿/交付身份、外部恢复点|局部测试只报局部结果；人类/独立盲评/作者签收分别保留状态|

“行动者/现金流/支付”仅在相应经济机制确实相关时检查；科学解释与历史叙事不必硬填。不能以“读者可行动”排除理解世界本身的价值。

跨域写作必须在目标领域重新建立机制并说明不等价处；经济题材的价格、现金流、权利义务和参与者约束仍需核实。它们不是可因通用化而省略的实质检查。找不到严谨对应时允许只讲源领域、放弃迁移或不成章。

## 有缺陷就落实修改，无缺陷可以保留

按 [EDITORIAL_LOOP](EDITORIAL_LOOP.md) 执行。结构审查最多抓最影响读者的1—3处：引用段落 → 解释为什么有问题 → 指出证据缺口或理解断点 → 改写 → 对照是否解决。没有实质缺陷可以记录0项、给出保留依据并标 KEEP，不为凑审稿次数改好段落。只写“更深、更流畅、更有洞见”不算审稿。

原生研究隔离的是**预设结论**，不是作者身份。立项时保留作者的提问、价值边界和声音偏好；研究阶段不把历史母题当事实；结构成立后再以合法样本校准语气，避免逐句仿写。

作者提供的第三方参考文章用于研究与表达比较，不自动等于作者本人声音。作者对局部稿件、项目成果的实际认可应如实记录，既不抹成“只有模型自评”，也不扩大成所有版本/全书/独立盲评签收。

## 执行与作品边界

同一活跃回合内，按研究→成稿→审查→返工连续推进已授权范围，不把内循环或每次跨章审拆成用户必须回复的“下一步”。分别记录章内自主、跨章自主、方向诊断及所需作者输入，不能由其中一项推定整书E1通过。会话结束后的后台执行仍须真实执行器。

正文交付必须能让读者直接阅读/下载，不用“文件已存”和审稿摘要替代。目录、总纲、前后文缺件也属于真实成品缺口。作者提出新受众、书名或续作时，先判断这是探索、当前修订还是后续项目；明确要求保留本部时停止擅自重构，另记设计债与续作方向。

模型“首次读者”只能发现可能的理解问题；真正读者复述、陌生情境迁移与独立人类审稿单列。一个模型的多个角色不等于多个独立评委。

## 成本与停止规则

先定本轮工具/时间或 token 预算、篇幅和最高风险。连续两次返工没有具体改善，或写作以新发现数量而非证据为目标，停止扩写并重查素材、范围、章节设计。低风险过渡段不强制走完整研究循环。正文变更后只重审受影响项及其依赖，但所有旧 PASS 都仍绑定旧身份；未完成重新绑定的项保持 PENDING。

新增评测分层见 [EVALUATION](../EVALUATION.md)：E0 是开发证据，不等于 E1 完整成书或 E2 质量泛化。候选的质量提升尚待真实读者和公平盲评验证。
