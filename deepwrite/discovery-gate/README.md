# Discovery Gate (proposed, not active)

Reusable, source-agnostic DeepWrite ideation gate. **No private project data in this public directory.**

Read `PROPOSAL_v0.2.md`, then `REVIEW_PROTOCOL_v0.2.md`. Run `discovery_gate.py` to validate a local JSON containing `cards`. See the *prose spec* for the required schema and human review gates. Use your own private data files outside public repositories.

A passing structural check says only that required fields exist and a few simple list/text conditions hold. It does not prove semantic diversity, empirical truth, original ideas, or human improvement. Do not set the active DeepWrite version from this prototype alone.
