# DeepWrite Discovery Gate｜思想发现前置关（候选 v0.2）

状态：`PROPOSED_NOT_ACTIVE`。本目录是面向多模型的通用规范，不含用户私人书稿、案例、密钥或对话。`deepwrite/CURRENT.json` 保持原有生效版本，未经独立实测和作者批准不得升级。

## 目标及非目标

**目标**：在目录/章节写作之前，主动发现能解释异常、提出**不同且可观察预测**、能被反驳、能改变具体决策的认知命题；并清楚标示已有理论与新应用。

**非目标**：保证每轮提出原创学术理论；让同一模型模拟真人盲审；用大纲、创意清单或漂亮修辞替代长书；让现有模型无人工接力地持续在后台运行。

## 两个进程不能合成一步

1. `DISCOVER`: 原始材料与现象→矛盾池→竞争性因果解释→差异预测→反事实→先例/事实核验→决策卡→外部读者测试。
2. `DEEPWRITE`: **通过发现关后的**独立命题→读者能力图→样章→整书→稿件审读与源验证→作者批准。

若假设太少，允许把书缩短、换题或判定 `STOP_WORK_NO_BOOK`。不准为凑字数把一个命题稀释为十章。

## 硬性阶段

### Gate D0：Clean Room（独立构思的诚实定义）

从原始目标、观察和源稿提取问题。若操作人已经读过旧版/答案，必须标记 `CLEAN_ROOM_CONTAMINATED`；不得声称由另一份空白独立推导。项目私人材料只能进入私有项目库。

### Gate D1：矛盾池

至少六条独立反例、张力或不能解释的现象，分别标明 `OBSERVED_WITH_SOURCE`、`HYPOTHETICAL`、`OPEN_QUESTION`。真实个案必须具备可核链接及限定时间/对象。

### Gate D2：平行机制

针对至少两项重要矛盾，每项不少于三种**真正不同的因果机制**。必须含激励、瓶颈、竞争进入、时间与反馈。允许“原始中心观点是错误的”。只有不同表述没有不同预测，判 `FAIL_SEMANTIC`。

### Gate D3：反事实预测

至少两条条件性预测：说明 A/B 机制各会在何条件下预测什么不同的**可观察量**。反例、已知不适用范围必须写出；没有可区分预测即 `HOLD`。

### Gate D4：先例及证据

逐项查学术/行业已有理论、原始来源和观察条件。分类：`NEW_TO_SOURCE`、`APPLICATION_VALUE_CANDIDATE`、`POSSIBLY_NOVEL_UNVERIFIED`、`NO_NOVELTY`。前人研究中已有的理论不可自称首创；同类研究只有相关性也不能说因果已验证。

### Gate D5：决策变化

设计一个相同信息、读前/读后两个选择的案例。决策变化需有相应事实条件，并解释**什么时候不该改变**。读者称赞“有道理”不算通过。

### Gate D6：人工独立与停工

结构工具通过只给 `PASS_STRUCTURAL`。**内容**必须分 `HYPOTHESIS_UNVERIFIED`、`RESEARCH_REQUIRED`、`HUMAN_REVIEWED`。第三方盲审必须是真人或可证明独立的评审，不允许同一模型换角色冒充；没有证据不要升级 `PASS_QUALITY`。

## 验收的明确失败条件

- 同义 rival→`FAIL_SEMANTIC`
- 只有“不是X而是Y”→`HOLD_MECHANISM`
- 预测没有可观察量→`HOLD_MEASURE`
- 无反证/无法改变选择→`REJECT_LOW_INCREMENT`
- 本地/行业统计无可靠原始来源→`RESEARCH_REQUIRED`
- 主要理论在先例中出现，却宣称学术原创→`FAIL_NOVELTY_CLAIM`
- 未取得独立评审而声称实验质量胜出→`FAIL_EVALUATION`
- 原稿或标明私有的材料上传公开库→`FAIL_PRIVACY`

## 可执行工具及它不做的事

`discovery_gate.py` 仅做**结构门**（至少三种对手机制、两种不同条件的预测、反证、决策题、来源条目等），绝不会给思想真实性和新颖性自动高分。

```bash
python3 discovery_gate.py cards.json --report validation.json
python3 -m unittest discover -s tests -v
```

源码和测试无额外依赖，适合AI自行拉取后使用。每个失败要带字段名和修复方向；报告需附原候选SHA。

## 何时允许正式升级

先通过回归测试（同一材料、预先固定来源和预算的旧 vs 新思考过程）；然后再至少三个**未用于设计流程的陌生主题**上做隔离、等总资源、匿名评审。独立读者用机制、差异预测、反证、读前读后决策变化、事实来源五维逐项引段评分。必须公布样本量、审稿分歧、失败卡、人工介入次数；确认有价值才申请修改 `deepwrite/CURRENT.json`。
