PRIVATE PREPARATION / PUBLIC COMMIT

写好再发，不必先授权。

把已经写好的文章粘贴进来，核对排版，然后复制 Markdown。用你现有的 GitHub 登录状态提交文件，网站就会按原来的发布链路更新。

私密边界：这页不会上传内容、也不会自动保存草稿。关闭或刷新前请先下载备份；一旦在公开 GitHub 仓库点击 Commit，文章及历史记录就对外可见。

01 / 整理文章

所有输入仅留在当前浏览器页面
文件只在本机读取，不上传。

02 / 核对呈现

填写标题、摘要与正文后，点击「刷新预览」。这里使用和正式网站相同版本的 Markdown 渲染器。

03 / 由你确认并发布

真正的发布发生在 GitHub Commit

这条路线不需要另外生成 GitHub Token，但需要你在 GitHub 网页中登录 TaoismZp，并且有仓库写入权限。

文件名将在填写文章后生成。

去 GitHub 新建文件 ↗

  1. 先点击「复制完整发布稿」，再打开 GitHub。文件名将尝试预填；如果没有预填，使用上方显示的文件名。
  2. 将内容粘贴到 GitHub 编辑区，选择 Commit changes 并提交到 main，才会公开发布。
  3. GitHub Pages 自动构建后，打开 长文列表 检查文章。若要直接可视化编辑，也可使用 Sveltia 写作台（需要限定仓库的 Token）。

这是一条便于首次发文的备用通道，不会替代 Sveltia 后台。当前仍不能声称站长本人已经完成真实发布验收。
