## 核心玩法

- 24 格环形棋盘；
- 12 种链上资产，分为 CORE / BETA / INFRA / YIELD 四个板块；
- 无主资产可买入；别人落在你的资产上要支付链上过路费；
- 落在自己资产上可以继续加仓，最高 3 级；
- 集齐一个完整板块，过路费提高 50%；
- 市场每轮在牛 / 熊 / 狂热 / 恐慌 / 震荡间切换，改变资产估值和现金流；
- Airdrop、Gas、Rug、Hack、ETF、清算、Halving 等特殊格与事件抉择；
- 现金不足会自动折价卖资产；救不回来则爆仓出局；
- 12 轮后按净值排名，或玩家爆仓时提前结算；
- 自动保存，可断点续玩；
- 结局会给出你的「链上人格」。
