## 1. Binding Chain
Every supervision report is invalid unless it binds all four identities:
1. **Vision Fixture**: `REFERENCE_FIXTURE.md` + locked effect-image SHA-256.
2. **Controlling Blueprint**: this file path + current Git blob SHA.
3. **Candidate**: exact candidate commit SHA + candidate version marker.
4. **Evidence**: exact workflow run + artifact/screenshots produced from that candidate.

Final acceptance adds a fifth identity: the exact public Delivery Surface build.

A PASS against an older/easier blueprint is void. A screenshot from a different commit is void. A localhost build cannot prove a different public build.

6. character collectible quality

## 5. Current Stage-1 Construction Order — v7 Family
`SUPERVISION_REPORT_V6.md` is the current defect source. v7 is permitted to address only those blockers before gameplay expansion.

### A. Center hierarchy
- remove/hide the conflicting old English monument and opaque v6 plaque;
- replace with an open, transparent/live-geometry crest that leaves the globe and dice readable;
- Chinese `币圈大富翁` remains the dominant brand read.

### B. Environment authorship
- suppress the repeated procedural skyline wall;
- create near/mid/far spacing;
- emphasize distinct exchange, BTC, ETH and market-terminal hero structures.

### C. Character collectible quality
- improve silhouette and signature accessories/material separation of the four player pieces;
- do not use emoji or flat character screenshots.

### D. Lighting balance
- reduce over-hot foreground local lights;
- add controlled broad fill so skyline and hero pieces remain readable without bloom as camouflage.

### E. Tile storytelling
- keep real physical 24-tile loop;
- Chinese titles and consequences must remain legible at the locked camera;
- far tiles may simplify secondary copy rather than shrink everything.

No full-game expansion until a supervisor report explicitly PASSes this blueprint.
