# Personal Site Frontend Bakeoff

Status: ACTIVE — capability procurement only. No backend work is allowed in this phase.

## Representative task
Build only the public personal-site homepage for TaoismZp using the same content and same functional scope. The homepage must establish a person first, not a blog product: trader / writer / researcher; selected longform is one major module; books/projects are another; no CMS, auth, database, publishing workflow, or admin UI.

## Quality variables (weighted)
1. Personal identity / first-impression distinctiveness — 25%
2. "Personal site, not blog" information architecture — 20%
3. Longform reading/editorial credibility — 15%
4. Visual craft and typography — 15%
5. Mobile responsiveness / touch quality — 10%
6. Accessibility and interaction restraint — 5%
7. Extendability to future projects, notes, about, media — 10%

## Competitors
- baseline: no external design skill; control.
- anthropic: Anthropic `frontend-design` principles.
- impeccable: Impeccable new-work / Experience+Read craft principles.
- uiux: UI/UX Pro Max design-system / UX priority principles.

## Non-directional quality gates (not competitors)
- `make-interfaces-feel-better`: micro-polish pass after direction is chosen.
- Vercel `web-design-guidelines`: accessibility / web-interface audit after direction is chosen.

## Hard rules
- Same core content across all four.
- No stock imagery or AI-generated hero art in the bakeoff.
- No backend implementation.
- A visually weak candidate cannot win because it has more features.
- Winner is a minimum stack, not a popularity contest.
